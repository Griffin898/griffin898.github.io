# Składanka dla Króliczka

Słodka gra merge dla Julii. Stukasz donicę, kuchnię albo biurko, łączysz dwa identyczne przedmioty w coś wyższego i oddajesz komplet Króliczkowi, Konrasowi albo Gwiazdce. Za monety rozbudowujesz generatory i planszę.

Cała gra jest w jednym pliku `index.html`. Obok zostają dawne strony: `bukiet.html`, `gift.html` i `cart.html`, plus obrazki w `assets/`.

## Jak wrzucić na GitHub

Wgraj cały folder (albo samą zawartość zipa) do repozytorium. Na stronie użytkownika `username.github.io` plik `index.html` ma leżeć w katalogu głównym. Nie trzeba `npm`, Vite ani budowania.

Zapis gry siedzi w przeglądarce, klucz `kroliczek-merge-v2`. Sklep otwiera się pod `#/shop`.

## Lokalnie

Otwórz `index.html` w przeglądarce albo uruchom dowolny serwer statyczny w tym katalogu:

```bash
python3 -m http.server 47421
```

Potem wejdź na [http://127.0.0.1:47421/](http://127.0.0.1:47421/).
